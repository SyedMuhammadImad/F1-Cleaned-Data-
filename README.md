# Formula One exploratory data analysis

Constructor, driver and circuit analysis of supplied historical Ergast-style CSV files. Fastest laps use minimum lap time in seconds. Position gains are labeled as a grid-to-finish proxy; they are not overtaking counts. Nonfinish status includes more than retirements. `python analyze.py --data-dir "path/to/F1 data" --output analysis.json` reproduces ten analysis tables. Circuit layouts can change across years.

Install `requirements.txt`. Fresh numeric results and the completed verification checks are included. Pictures, videos and credentials are omitted. Original laptop copies are preserved.
